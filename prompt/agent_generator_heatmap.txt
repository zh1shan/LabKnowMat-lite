5. IMPORTANT FOR HEATMAP: A file named 'heatmap_data.json' exists in the current directory. It contains the raw normalized matrix data formatted as a 2D JSON array (a list of lists of floats) with dimensions 128x128. You MUST load this file using `import json` and use it as the actual data source (Z matrix) for your heatmap. STRICTLY FORBIDDEN to generate random, synthetic, or Gaussian data using numpy. You must use the data from the json file.
6. CRITICAL ORIENTATION RULE: The matrix in 'heatmap_data.json' is stored in IMAGE COORDINATES — row 0 corresponds to the TOP of the original chart image, and the last row corresponds to the BOTTOM. When calling `ax.imshow()`, you MUST use `origin='upper'` (which is the default) to preserve the correct orientation. You are STRICTLY FORBIDDEN from using `origin='lower'`, as it will flip the heatmap upside down.
